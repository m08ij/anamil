# أنامل — مدرّب الكتابة السريعة

موقع لتعلّم الكتابة السريعة على الكيبورد بالعربية والإنجليزية.

## المميزات
- **اختبار تحديد مستوى** (60 ثانية) لكل لغة قبل البدء.
- **تدريب تكيّفي**: يفتح الحروف تدريجياً للمبتدئين، ويركّز على أضعف حروفك، ويعيد الكلمات اللي غلطت فيها حتى تكتبها صح 3 مرات.
- **جمل حقيقية** بعلامات ترقيم وأحرف كبيرة، مختارة حسب حروفك الضعيفة.
- **اختبار سرعة** بمدة 15 / 30 / 60 / 120 ثانية مع رسم بياني.
- **تحليل الأخطاء المتكررة**: يعرف أي حرف بتكتب بدل أي حرف، يصنّف السبب (مفتاح جار، Shift، خلط بين اليدين...) ويعطيك نصيحة وتمرين تلقائي.
- **👻 شبح نسختك**: مؤشر بيسابقك بسرعة أفضل نتيجة إلك (أو متوسطك أو هدفك).
- **🔗 ثنائيات الحروف**: بيعرف أي تركيبات حرفين بتبطّئك ويدرّبك عليها.
- **ثيمات وتخصيص**: 6 ثيمات، خطوط عربية وإنجليزية، حجم النص، وشكل المؤشر، بلوحة إعدادات جانبية.
- **أنيميشن**: عدّاد سلسلة، أرقام بتعد، احتفالات بالقصاصات، وانتقالات ناعمة.
- **💻 وضع البرمجة**: كود JavaScript و Python حقيقي، و Enter لسطر جديد مع مسافات تلقائية.
- **⚡ تمرين الضعف**: دقيقة وحدة على أضعف 3 حروف عندك.
- **🎮 لعبة الكلمات النازلة**: اكتب الكلمة قبل ما توصل للأرض، مع مستويات وأرواح ونقاط.
- **🎵 الإيقاع و 🙈 بدون نظر**: نبضة ثابتة تكتب عليها، ووضع بيخبّي الكيبورد والنص البعيد.
- **🏅 21 إنجاز**، و**4 حزم أصوات** (ناعم، ميكانيكي، آلة كاتبة، فقاعات).
- **📱 موبايل وتابلت**: كيبورد الجهاز، وتصميم مناسب للشاشات الصغيرة، وتثبيت كتطبيق يشتغل بدون إنترنت.
- **إحصائيات**: منحنى التقدّم، خريطة أخطاء على الكيبورد، أضعف الحروف.
- كيبورد على الشاشة يوضّح المفتاح التالي والإصبع المناسب، وتحويل تلقائي إذا كانت لغة الكيبورد غلط.
- وضع ليلي/نهاري، أصوات، وحفظ التقدّم في المتصفح.

## التشغيل
افتح `index.html` في المتصفح، ما في أي خطوة بناء.

## الاختصارات
`Tab` إعادة · `Esc` درس جديد · `Ctrl+Backspace` حذف كلمة · `Enter` التالي
